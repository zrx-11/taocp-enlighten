# 综合检验建议

读完六本之后，用下面几道题检验「系统掌握」。它们都要求同时调用两本以上书的内容，单靠一本书答不完整。

## 跨书整合题

### 题 1：给一个日志系统选排序方案
- 涉及：卷3 第 2、4 章；卷2 第 1 章；MMIX 第 3 章
- 场景：每天 200 GB 日志，每条 200 字节，需要按时间戳排序后归档；单机内存 32 GB，磁盘顺序读 500 MB/s。
- 要求：给出方案（初始游程大小、合并路数、预计趟数、总 I/O 量），并说明为什么不用快排。
- 评分要点：
  1. 算出记录数约 10⁹，初始游程数 R 与游程大小 P 的关系正确。
  2. 趟数用 ceil(log_k R)，k 的取值说明内存约束。
  3. 总 I/O 量按 2N×趟数估算，并说明最后一遍只读不写。
  4. 指出「内存装不下」是排除内部排序的唯一理由。

### 题 2：设计一个可复现的实验随机源
- 涉及：卷2 第 1、2 章；卷1 第 1 章（可复现性）
- 场景：要跑 100 万次蒙特卡洛模拟，要求同一 seed 结果完全一致，且不同 seed 之间统计独立。
- 要求：选一种发生器、给出参数、设计三项检验、说明如何洗牌。
- 评分要点：
  1. 说明为什么选线性同余或组合发生器，参数满足满周期条件。
  2. 卡方检验的分格、期望频数下限、自由度。
  3. 洗牌必须是 Fisher-Yates，指出全范围交换的偏斜。
  4. 说明「可复现」与「独立样本」不是一回事。

### 题 3：从布尔函数到生成算法
- 涉及：卷4A 第 1、4 章；卷4B 第 1、2 章
- 场景：要枚举一个 6 变量布尔函数的所有满足赋值，并统计个数。
- 要求：给出两种方法（真值表枚举、BDD 上动态规划），比较代价。
- 评分要点：
  1. 真值表法 2^6 = 64 次求值，说明 n 增大后的爆炸。
  2. BDD 法按图的大小计，说明变量顺序的影响。
  3. 枚举与计数是两类问题，方法不同。
  4. 若还要「列出」而不只是「计数」，说明输出规模本身就是下界。

### 题 4：把卷3 的查找结构搬到磁盘
- 涉及：卷3 第 5、6 章；MMIX 第 3 章
- 场景：10 亿条键值记录，键 16 字节，值 100 字节，要支持点查与前缀范围查。
- 要求：选 B 树或 LSM 类结构，估算层数与每次查询的 I/O 次数。
- 评分要点：
  1. 扇出与层数的关系 log_m n。
  2. 点查 I/O 次数约等于层数。
  3. 范围查的代价取决于叶子链表与块大小。
  4. 指出散列不支持范围查，所以不能只考虑 O(1)。

### 题 5：解释「为什么 n log n 是下界，但基数排序能线性」
- 涉及：卷3 第 3 章；卷4A 第 1 章（位表示）
- 要求：写一段不超过 300 字的解释，必须点明「比较模型」与「字长模型」的差别。
- 评分要点：
  1. 下界来自比较树的叶子数。
  2. 基数排序不做元素间比较，按位分配。
  3. 线性是对「字长固定」而言；键很长时 d 增大，仍是线性但常数大。
  4. 不把「线性」说成「绝对比 n log n 快」。

2. **偏工程**：卷3 第 5.4、6.4 节 → 卷2 第 4.3 节 → MMIX 全书。走存储、散列、多精度的实现路线。
3. **偏竞赛**：卷4A 第 7.2 节 → 卷4B 全书 → 卷3 第 5.2 节。走组合生成与排序实现的路线，重点是手写代码。
