# 跨书总览：TAOCP 六书学习路线

这套知识库把六本 TAOCP 中文版做成了一条可以按顺序推进的路线。目标不是「读完」，而是**系统掌握**：读完能自己判断一个算法场景该用什么结构、代价大概多少、什么时候会退化。

## 推荐学习顺序

| 顺序 | 书 | 为什么在这个位置 | 能力里程碑 |
|---|---|---|---|
| 1 | 卷1 基本算法 | 全书的地基：算法分析、数学工具、MIX、线性表、树。后面五本都默认你懂这里的记号 | 能写出 O 记号、能手算一个算法的平均代价、能解释栈与链表 |
| 2 | 卷2 半数值算法 | 只依赖卷1 的数论与算术基础；随机数与浮点是后面排序、组合实验的工具 | 能设计并检验一个伪随机数发生器，能解释浮点误差 |
| 3 | 卷3 排序与查找 | 依赖卷1 的树与卷2 的概率工具；是「算法分析」最完整的一次实战 | 能算比较次数下界、能算外部排序趟数、能选对查找结构 |
| 4 | 卷4A 组合算法（一） | 依赖卷1 的排列组合与卷3 的算法分析；开始处理指数级问题 | 能表示并化简布尔函数、能写出不重不漏的生成算法 |
| 5 | 卷4B 生成元组与排列 | 卷4A 第 7.2 节的展开；最短的一册，适合作为组合算法的收尾 | 能实现字典序、格雷码、相邻交换三类生成 |
| 6 | MMIX 增补 | 旁注性质：把卷1 至卷3 的算法落到真实机器上。可以在任意阶段穿插读 | 能读懂 MMIX 汇编、能解释栈帧与协同程序 |

## 各书定位（一句话）

- **卷1 基本算法**：定义「算法分析」这门手艺，给出全书共用的数学工具箱与数据结构底座。
- **卷2 半数值算法**：处理两类算不准的东西——随机与实数，教你把近似变成可控的近似。
- **卷3 排序与查找**：把「排」与「找」的代价算到常数级，并给出 n log n 的信息论下界。
- **卷4A 组合算法（一）**：从 0 与 1 讲到生成全部组合对象，正面处理组合爆炸。
- **卷4B 生成元组与排列**：把「生成」这一个动作打磨到每次只改一位。
- **MMIX 增补**：抽象算法的机器级注解，看清「落到硬件要多做哪些事」。

## 学习节奏建议

- **第一轮（8 到 10 周）**：卷1 全部 → 卷2 第 1、3 章 → 卷3 第 1、2、5 章。每周 6 到 8 小时，先求「看懂并算得出代价」。
- **第二轮（6 到 8 周）**：卷3 剩余章节 → 卷4A 第 1、4 章 → 卷4B。重点是动手实现，不只看。
- **第三轮（4 周）**：卷2 剩余章节、卷4A 第 2、3 章、MMIX。这一轮做跨书整合题。
- **交叉复习**：每读完一本，回到《跨书概念映射表.md》，看同一个概念在其他书里怎么讲；差异处往往就是理解不到位的点。

## 总入口

打开 `index.html` 总学习手册，按顺序推进；每本书的进度独立保存，测验按章拆开，抽认卡可以按标签筛。
