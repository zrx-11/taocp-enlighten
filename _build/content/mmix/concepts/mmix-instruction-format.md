# MMIX 指令格式

- **难度**：基础 | **涉及章节**：第 1 章

## 一句话定义

MMIX 每条指令 32 位，由 opcode 与三个 8 位字段（x、y、z）组成，常见形式是三地址：目的寄存器、两个源。

## 为什么重要

读懂格式，才能读懂汇编、估算指令条数、理解「为什么 MMIX 的常数零寄存器很关键」。它也是 RISC 设计思想的典型样本：定长指令、字段规整、load-store 分离。

## 图示

```mermaid
flowchart LR
    O[opcode 8 位] --> X[x 8 位]
    X --> Y[y 8 位]
    Y --> Z[z 8 位]
```

四个字段拼成 32 位；x 通常是目的，y、z 是源或「源加立即数」。

## 详解

**三种常见形态**：
- 三寄存器：`ADD $1, $2, $3`。
- 寄存器加立即数：`ADD $1, $2, 5`。
- 加载/存储：`LDO $1, $2, 16`，基址加字节偏移。

**$0 恒为 0**：读恒为 0、写无效，可当常数零用。

**字节寻址**：地址按字节计，8 字节元素间隔为 8。

**实例**：读两个数相加存回：
```
LDO $1, $0, 0x100
LDO $2, $0, 0x108
ADD $3, $1, $2
STO $3, $0, 0x110
```

## 常见误解

- 别以为一条指令能做多件事：RISC 风格下，运算与访存严格分开。
- 别以为偏移量是元素下标：它是字节偏移，要乘 8。
