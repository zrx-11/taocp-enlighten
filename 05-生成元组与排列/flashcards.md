# 计算机程序设计艺术 卷4B：生成所有元组和排列 · 抽认卡

## 第 1 章：生成所有 n 元组

### 卡片：k 进制 n 位元组共有多少个？
- **背面**：k^n 个，每位独立取 k 种值。
- **标签**：元组
- **章节**：ch01

### 卡片：二进制转格雷码的公式？
- **背面**：g = b ⊕ (b >> 1)，即第 i 位等于 b 的第 i 位与第 i+1 位异或。
- **标签**：格雷码
- **章节**：ch01

### 卡片：格雷码的反射构造怎么描述？
- **背面**：n 位 = 0 前缀的 n−1 位格雷码 + 1 前缀的 n−1 位格雷码倒序。
- **标签**：格雷码
- **章节**：ch01

## 第 2 章：生成所有排列

### 卡片：求字典序下一个排列的四步？
- **背面**：找最右升序对 i、找最右大于 a[i] 的 j、交换、反转 i 右侧。
- **标签**：排列
- **章节**：ch02

### 卡片：排列的排名怎么算？
- **背面**：对每位数「右边比它小的元素个数」，乘以对应阶乘权，再加总；从 0 开始。
- **标签**：排列
- **章节**：ch02

### 卡片：Heap 算法做多少次交换？为什么？
- **背面**：n!−1 次；每次交换都产生一个新排列，新排列总数是 n!−1。
- **标签**：排列
- **章节**：ch02

### 卡片：圆排列与带重复元素排列的种数？
- **背面**：圆排列 (n−1)!；带重复 n!/(n1!n2!…)。
- **标签**：排列
- **章节**：ch02
