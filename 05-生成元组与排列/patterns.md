# 模式与框架库

## 框架：选一种生成方式

1. **只需要全部对象、不关心顺序** → 二进制计数或递归，最简单。
2. **相邻对象要尽量相似** → 格雷码或相邻交换。
3. **需要随机访问第 k 个对象** → 阶乘数系统直接算排名与还原。
4. **每位进制不同** → 混合基计数。

## 决策规则：判断「下一个」是否唯一

- 字典序：下一个是「最右可增位加一、右侧重置为最小」。
- 格雷码：下一个是「翻转哪一位由当前步数的二进制决定」。
- 相邻交换：下一个是「按递归结构决定交换哪一对」。

## 反模式

- **用递归生成排列却不撤销交换**：后续分支会基于错误状态。
- **格雷码与二进制码混用**：转回普通二进制要异或前缀，忘了就全错。
- **用 n! 直接算排名**：大 n 会溢出，要用阶乘数系统逐位算。
