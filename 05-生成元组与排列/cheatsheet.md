# 速查表

## n 元组

| 项目 | 内容 |
|---|---|
| 总数 | k^n（每位 k 种取值） |
| 二进制计数 | 从 0 到 2^n−1 |
| 格雷码 | g = b ⊕ (b >> 1) |
| 逆转换 | b = g ⊕ (g >> 1) ⊕ (g >> 2) … |

## 排列

| 项目 | 内容 |
|---|---|
| 总数 | n! |
| 圆排列 | (n−1)! |
| 字典序下一个 | 找最右升序对、交换、反转右侧 |
| 排名 | 阶乘数系统逐位累加 |
| Heap 算法交换次数 | n! − 1 |

000 → 001 → 011 → 010 → 110 → 111 → 101 → 100
