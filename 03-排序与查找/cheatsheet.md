# 速查表

## 排序代价

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|
| 直接插入 | n² | n² | 1 | 是 |
| 希尔 | 约 n^1.3 | 依间隔序列 | 1 | 否 |
| 冒泡 | n² | n² | 1 | 是 |
| 快速排序 | n log n | n² | log n | 否 |
| 直接选择 | n² | n² | 1 | 否 |
| 堆排序 | n log n | n log n | 1 | 否 |
| 合并排序 | n log n | n log n | n | 是 |
| 基数排序 | d(n+k) | d(n+k) | n+k | 是 |

## 查找代价

| 结构 | 平均 | 最坏 |
|---|---|---|
| 顺序查找 | n/2 | n |
| 二分查找 | log n | log n |
| 二叉查找树 | 1.39 log n | n |
| AVL / 红黑树 | log n | 1.44 log n |
| B 树 | log_m n 层 | 同 |
| 散列（链地址） | 1 + α/2 | n |

## 关键公式

| 场景 | 公式 |
|---|---|
| 比较排序下界 | log2(n!) ≈ n log2 n − 1.44n |
| 外部合并趟数 | ceil(log_k R) |
| 替代选择游程 | 平均 2P |
| 链地址成功查找 | 1 + α/2 |
| 线性探测成功查找 | (1/2)(1 + 1/(1−α)) |
