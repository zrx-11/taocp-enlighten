# 计算机程序设计艺术 MMIX 增补 · 测验

## 第 1 章：MMIX 的寄存器、内存与指令

### Q1. MMIX 有多少个通用寄存器？（填数字）
**答案**：256
**解析**：编号 0 到 255，每个 64 位，其中 0 号恒为 0。

### Q2. LDO $1, $2, 16 中 16 的单位是？
- A. 位
- B. 字节
- C. 字（8 字节）
- D. 页
**答案**：B
**解析**：MMIX 偏移量按字节计，访问第 k 个 8 字节元素要写 k×8。

### Q3. MMIX 的 0 号寄存器有什么特殊之处？
- A. 存返回地址
- B. 恒为 0，写无效
- C. 存栈指针
- D. 存程序计数器
**答案**：B
**解析**：读 $0 恒得 0，写 $0 不生效，可当常数零使用。

## 第 2 章：汇编、子程序与协同程序

### Q1. PUSHJ $9, SUB 的作用是？
- A. 只跳转
- B. 压栈 $9 旧值、写返回地址、跳转
- C. 只压栈
- D. 只保存返回地址
**答案**：B
**解析**：PUSHJ 同时完成压栈、写返回地址与跳转三件事。

### Q2. 两层嵌套调用时，栈里最少保存几份返回地址？（填数字）
**答案**：2
**解析**：每层各存一份，否则内层会覆盖外层的返回地址。

### Q3. 协同程序与子程序的根本差别是？
- A. 协同程序更快
- B. 协同程序是对称交替、双方状态都保留
- C. 协同程序不能返回
- D. 协同程序必须多线程
**答案**：B
**解析**：子程序是调用—返回的单向关系；协同程序双方都能暂停与恢复，各自有独立栈。

## 第 3 章：卷1 至卷3 的 MMIX 重写

### Q1. MMIX 相比 MIX，字长与字节宽度的变化是？
- A. 32 位到 64 位，6 位字节到 8 位字节
- B. 16 位到 32 位
- C. 不变
- D. 64 位到 128 位
**答案**：A
**解析**：MMIX 是 64 位机器，字节 8 位；MIX 是 32 位、6 位字节。

### Q2. 双链表删除一个已知节点需要修改几个指针？（填数字）
**答案**：2
**解析**：前驱的 next 与后继的 prev，两条赋值即可。

### Q3. 为什么 64 位下链表相对数组更不划算？
- A. 指针占 8 字节且节点分散，空间与缓存都更差
- B. 链表不能存 64 位数据
- C. 链表不能删除
- D. 数组不能随机访问
**答案**：A
**解析**：指针开销翻倍，节点分散导致缓存命中率低；数组连续存放更省空间也更快。

## 综合测验

### 综合 Q1. 综合题：要把卷3 的外部排序移植到 MMIX，最需要重新考虑的是？
- A. 比较次数公式
- B. 块大小、缓冲区数量与 I/O 合并
- C. 趟数公式
- D. 记录的逻辑顺序
**答案**：B
**解析**：趟数公式不变；变的是每趟耗时，由块大小、缓冲区与 I/O 合并方式决定。
