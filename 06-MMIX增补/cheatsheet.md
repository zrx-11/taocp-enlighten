# 速查表

## 机器规格

| 项目 | 内容 |
|---|---|
| 通用寄存器 | 256 个，每个 64 位，$0 恒为 0 |
| 地址空间 | 2^64 字节 |
| 指令长度 | 32 位，含 opcode 与三个操作数字段 |
| 字节序 | 大端（高位字节在低地址） |

## 常用指令

| 动作 | 指令 |
|---|---|
| 加载 8 字节 | LDO / LDV |
| 存储 8 字节 | STO / STV |
| 加法 | ADD |
| 比较 | CMP |
| 条件跳转 | BZ / BN / BP |
| 调用子程序 | PUSHJ |
| 返回 | POP |

## 调用约定

| 项目 | 做法 |
|---|---|
| 参数 | 放 $1 起的高编号寄存器或栈 |
| 返回地址 | PUSHJ 压栈，POP 弹出 |
| 局部变量 | 栈帧内偏移寻址 |
| 返回值 | 放固定寄存器 |
