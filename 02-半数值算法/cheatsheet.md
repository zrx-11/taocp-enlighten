# 速查表

## 线性同余

| 项目 | 内容 |
|---|---|
| 递推式 | x(n+1) = (a·x(n) + c) mod m |
| 满周期三条件 | gcd(c, m) = 1；a−1 被 m 的所有素因子整除；m 被 4 整除时 a−1 也被 4 整除 |
| 模 2^e 的乘数 | a ≡ 5 (mod 8)，纯乘同余周期 2^(e−2) |
| 取范围 | 用高位，不要用低位 |

## 常用检验

| 检验 | 统计量 | 用途 |
|---|---|---|
| 卡方 | Σ(观测−期望)²/期望 | 频数是否均匀 |
| 柯尔莫哥洛夫 | 经验分布与理论分布的最大差 | 分布形状 |
| 谱检验 | 多维格点的最大空隙 | 相邻数的相关性 |

## 浮点与多精度

| 项目 | 内容 |
|---|---|
| 单精度 | 约 7 位十进制有效数字 |
| 双精度 | 约 16 位十进制有效数字 |
| 朴素乘法 | n 位 × n 位需 n² 次单位乘法 |
| 快速乘法 | T(n) = 3T(n/2) + O(n)，约 O(n^1.585) |
| 秦九韶 | n 次多项式只需 n 次乘法加 n 次加法 |

## 洗牌
