# 模式与框架库

## 框架：造一个可用的伪随机数发生器

1. **选类型**：需要长周期、可重复 → 线性同余；需要更高质量 → 组合多个发生器（如相加或异或）。
2. **选模**：模取 2 的幂便于硬件取余，但低位质量差；取素数（如 2^31−1）低位与高位一样好。
3. **选乘数**：模 2^e 时乘数取 a ≡ 5 (mod 8)，纯乘同余也能拿到 2^(e−2) 的周期。
4. **验周期**：m、c 互素，a−1 能被 m 的所有素因子整除，m 被 4 整除时 a−1 也被 4 整除 —— 三条齐了才是满周期。
5. **做检验**：卡方查均匀性，柯尔莫哥洛夫查分布形状，谱检验查多维相关性。

## 决策规则：随机数用哪种变换

- 只要均匀整数 → 直接用发生器的输出。
- 要 0 到 1 的实数 → 输出除以模，注意不要用到低位。
- 要正态分布 → Box-Muller（两个均匀数经对数与三角函数）。
- 要任意分布 → 逆变换法，前提是累积分布函数的反函数可算。
- 要随机排列 → Fisher-Yates 洗牌，从后往前，每次与前面随机位置交换。

## 反模式

- **用 rand() % n 取范围**。当 n 不整除发生器周期时会引入偏斜，正确做法是拒绝采样或先放大再取整。
- **把低位当高位用**。线性同余的低位周期很短（模 2^e 时第 0 位周期只有 2），要取高位。
- **用同一个种子跑两次实验还当成独立样本**。伪随机数可重复是优点，但重复的样本不是新样本。
- **浮点数直接用 == 比较**。应比较差值是否小于容差。
