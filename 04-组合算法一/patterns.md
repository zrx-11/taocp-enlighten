# 模式与框架库

## 框架：处理「所有可能」的五类问题

1. **存在性**：有没有解？先找必要条件、再构造或反证。
2. **构造**：给出一组解。常用贪心、递归、回溯。
3. **计数**：有多少解？用组合公式或生成函数。
4. **生成**：把全部解列出来。要求不重不漏，通常用递归树或格雷码。
5. **优化**：在全部解里找最好的。常与前三类结合。

## 框架：写一个生成算法

1. 确定「状态」：当前已经选了什么。
2. 确定「选择集」：下一步能选什么。
3. 确定「终止条件」：什么情况下输出一个完整解。
4. 加「剪枝」：不满足约束的分支提前返回。
5. 验证：输出数量是否等于公式算出的数量。

## 决策规则：怎么表示布尔函数

- 变量少（n ≤ 6）→ 真值表，直观。
- 需要代数化简 → 析取范式加化简。
- 需要频繁做等价性判断 → BDD。
- 需要批量求值 → 位并行或四 Russians 方法。

## 反模式

- **用回溯生成却不检查重复**：同一解被多条路径生成，数量对不上公式。
- **BDD 变量顺序随便定**：顺序选错，图的大小会指数膨胀。
- **拿真值表处理 30 个变量**：2^30 行，存不下也算不完。
