# 速查表

## 布尔代数

| 规则 | 内容 |
|---|---|
| 交换律 | a∧b = b∧a；a∨b = b∨a |
| 分配律 | a∧(b∨c) = (a∧b)∨(a∧c) |
| 德摩根 | ¬(a∧b) = ¬a∨¬b；¬(a∨b) = ¬a∧¬b |
| 吸收 | a∨(a∧b) = a |
| 异或 | a⊕b = (a∧¬b)∨(¬a∧b) |

## 规模公式

| 对象 | 数量 |
|---|---|
| n 变量布尔函数 | 2^(2^n) |
| n 位全部赋值 | 2^n |
| n 个元素的子集 | 2^n |
| C(n,k) | n!/(k!(n-k)!) |
| n 个元素的排列 | n! |

## 位技巧

| 目的 | 写法 |
|---|---|
| 清掉最低位的 1 | x & (x−1) |
| 取最低位的 1 | x & (−x) |
| 判断是否 2 的幂 | x>0 且 x&(x−1)=0 |
| 数 1 的个数 | 反复 x &= x−1，次数即答案 |
