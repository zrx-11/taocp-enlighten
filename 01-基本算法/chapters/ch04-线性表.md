# 第 4 章：线性表

- **难度**：★★☆ | **预估学时**：5 小时 | **前置**：第 1 章（代价分析）、第 3 章（地址概念）

## 学习目标

学完本章，你能：
1. 说出栈、队列、双端队列各自允许在哪一端操作，并判断一个实际问题该用哪个。
2. 在数组上实现栈，写清入栈、出栈与溢出判断。
3. 画出单链表插入与删除的指针变化，说清每一步为什么不能交换顺序。
4. 解释循环链表与双链表分别省掉了什么操作，什么时候值得多花一个链字段。

## 一句话核心

线性表的全部争论只有一个：**数据在内存里要不要挨着放**。挨着放换访问速度，散着放换插入删除的自由。

## 零基础讲解

### 概念 1：栈、队列与双端队列（难度：基础）

三者都是「只允许在特定位置插入删除」的线性表，区别在于允许的位置：

- **栈**：只在一端进出，后进先出。像一摞盘子，只能从顶上拿、往顶上放。
- **队列**：一端进、另一端出，先进先出。像排队买票，从队尾进、队首出。
- **双端队列**：两端都可以进出。栈和队列都是它的特例。

**实例**：依次压入 1、2、3 再全部弹出，顺序是 3、2、1。若入队 1、2、3，出队顺序是 1、2、3。
**用途**：栈用于表达式求值、递归的模拟、撤销操作；队列用于广度优先搜索、打印任务排队。

### 概念 2：顺序分配（难度：基础）

用一段连续的内存加一个指针实现栈：

- 数组 `V[1..m]` 存元素，整数 `TOP` 记录栈顶位置，初值 0 表示空栈。
- **入栈**：先判断 `TOP = m` 吗？是则上溢，拒绝；否则 `TOP = TOP + 1`，`V[TOP] = X`。
- **出栈**：先判断 `TOP = 0` 吗？是则下溢，拒绝；否则取出 `V[TOP]`，再 `TOP = TOP - 1`。

顺序分配的代价：按下标访问是 O(1)，但在中间插入要搬动后面所有元素，最坏 O(n)。

**队列的顺序实现有个坑**：用普通数组做队列，队首不断后移，前面会出现永远用不上的空位（假溢出）。解法是循环数组：`rear` 和 `front` 走到末尾就绕回 0，用「(rear + 1) mod m = front」判断满。

### 概念 3：链接分配（难度：进阶）

每个节点自己带一个「下一个节点在哪」的链，节点在内存里可以散着放。

一个节点记作 `INFO + LINK`：`INFO` 存数据，`LINK` 存下一个节点的地址。最后一个节点的 `LINK` 记 0（空链）。

**在 P 之后插入 Q**（顺序不能反）：
1. `Q.LINK = P.LINK`（先把 Q 接到 P 原来的后继上）
2. `P.LINK = Q`（再让 P 指向 Q）

如果先做第 2 步，P 原来的后继地址就丢了，链断在那里。

**删除 P 之后的 Q**：
1. `P.LINK = Q.LINK`（让 P 直接指向 Q 的后继）
2. 释放 Q

**实例**：链 A → B → C，在 A 之后插入 X。
1. `X.LINK = A.LINK`，此时 X 指向 B。
2. `A.LINK = X`，链变成 A → X → B → C。
若反过来先 `A.LINK = X`，A 原来的 `LINK`（指向 B）被覆盖，B 和 C 就找不回来了。

### 概念 4：循环链表与双链表（难度：进阶）

**循环链表**：最后一个节点指回第一个，整条链成一个环。好处是一个指针就能走遍所有节点，且「在尾部插入」不需要从头找尾部——只要指针指向尾节点，尾节点的 `LINK` 就是头。

**双链表**：每个节点存两个链，`LLINK` 指向前驱、`RLINK` 指向后继。好处是删除一个节点时不必先找到它的前驱。

删除节点 Q 的两步：
1. `Q.LLINK.RLINK = Q.RLINK`
2. `Q.RLINK.LLINK = Q.LLINK`

**代价**：每个节点多一个链字段，空间换时间。单链表删除必须先遍历找到前驱，最坏 O(n)；双链表是 O(1)。

### 概念 5：数组与正交表（难度：进阶）

二维表如果大部分格子是空的（稀疏），开满 `m×n` 数组会浪费大量空间。正交表用三个一维数组表示非零元素：

- `ROW[i]`：第 i 个非零元素的行号
- `COL[i]`：列号
- `VAL[i]`：值

再按行、按列各串一条链，就能从「某一行」或「某一列」快速找到非零项。稀疏矩阵转置、图的邻接表都用这个思路。

**实例**：3×3 矩阵只有 (1,2)=5、(2,3)=7、(3,1)=9 三个非零项。开满数组要 9 个格子，正交表只要 3 组三元组加两条链。

## 类比与实例

- 类比：顺序分配像一排固定座位的电影院，找第 5 排第 3 座一秒钟到位，但要在中间加一个人，后面所有人都得挪。链接分配像每个人手里牵着下一位的手，插入只要换两只手，但找第 100 个人得从头一个个数。
- 类比失效：电影院座位挪动是「物理搬人」，数组插入是复制数据；真实内存搬数据比搬人快得多，所以小数组上顺序分配往往比链表更快，这一点类比体现不出来。

**实例（栈操作复核）**：容量 m = 3 的栈，依次入栈 7、8、9，再出栈一次，再入栈 5。
- 入 7：TOP=1，V[1]=7
- 入 8：TOP=2，V[2]=8
- 入 9：TOP=3，V[3]=9
- 出栈：返回 V[3]=9，TOP=2
- 入 5：TOP=3，V[3]=5
最终栈内从底到顶是 7、8、5。若此时再入栈，TOP 已是 3 = m，触发上溢。

## 常见误解

- **别以为链表插入一定比数组快**——实际上「已经拿到插入位置」时链表才是 O(1)。若还要先按位置找到那个节点，查找本身是 O(n)，总代价并不比数组低。
- **别以为队列用数组实现只要两个下标就行**——实际上不循环就会假溢出，队列会越用越短。
- **别以为双链表删除只要改一条链**——实际上要改两条：前驱的 `RLINK` 和后继的 `LLINK`，漏一条链就断了。

## 自测题（答案）

1. 单选题：依次入栈 1、2、3、4，再连续出栈两次，得到的两个数是？
A. 1、2 B. 4、3 C. 3、4 D. 2、1
（答案：B；解析：栈后进先出，最先弹出的是最后压入的 4，然后是 3。）

2. 填空题：在单链表中删除 P 之后的节点 Q，第一步应执行 ___。
（答案：P.LINK = Q.LINK；解析：先让 P 越过 Q 指向 Q 的后继，链不断；再释放 Q。）

3. 简答题：为什么循环数组能解决队列的假溢出？
（答案：因为下标走到数组末端后绕回 0，把前面出队留下的空位重新用起来；判满条件改为 (rear + 1) mod m = front。解析：假溢出的根源是「队首后移造成前端空洞」，循环把线性空间变成了环，空洞被复用。）

## 复习锚点

- 栈后进先出、队列先进先出，双端队列两端都行。
- 链表插入两步：先接新节点的链，再改前驱的链。
- 双链表删除改两条链；循环链表用一个指针访问首尾。
