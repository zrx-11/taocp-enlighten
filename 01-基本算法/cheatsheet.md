# 速查表

## 常用求和与闭式

| 场景 | 结果 |
|---|---|
| 1 + 2 + … + n | n(n+1)/2 |
| 1 + x + x² + … + x^n | (1 − x^(n+1))/(1 − x)，x ≠ 1 |
| Σ C(n, k)，k 从 0 到 n | 2^n |
| 调和数 H_n | 约等于 ln n + 0.5772 |
| 斐波那契 F(n) | 约等于 φ^n / √5，φ = 1.618 |

## 复杂度对照

| 增长阶 | n = 1000 时的量级 | 典型来源 |
|---|---|---|
| O(1) | 1 | 数组按下标取 |
| O(log n) | 约 10 | 折半查找、平衡树 |
| O(n) | 1000 | 顺序扫描、链表遍历 |
| O(n log n) | 约 10000 | 归并排序、堆排序 |
| O(n²) | 100 万 | 双重循环、朴素排序 |

## 指针操作三步

| 操作 | 步骤 |
|---|---|
| 在 P 之后插入 Q | Q.LINK = P.LINK；P.LINK = Q |
| 删除 P 之后的 Q | P.LINK = Q.LINK；释放 Q |
| 双链表删除 Q | Q.LLINK.RLINK = Q.RLINK；Q.RLINK.LLINK = Q.LLINK |

## 树的遍历口诀

| 遍历 | 访问根的时机 | 序列特征 |
|---|---|---|
| 前序 | 先根，再左，再右 | 根排第一 |
| 中序 | 先左，再根，再右 | 排序树里得到升序 |
| 后序 | 先左，再右，再根 | 根排最后，适合释放节点 |

## 扩充二叉树

- 内部路径长度 I = 各内部节点深度之和。
- 外部路径长度 E = 各外部节点深度之和。
- 恒等式：E = I + 2n（n 为内部节点数）。
