# 生成函数

- **难度**：进阶 | **涉及章节**：第 2 章

## 一句话定义

生成函数把一整条数列打包成一个关于 z 的级数：G(z) = a0 + a1z + a2z² + …，数列的第 n 项就是 z^n 的系数。

## 为什么重要

它是解递推式的标准工具。算法分析里大量出现「a(n) 等于前几项的组合」，直接求通项很难；转成生成函数后，递推变成一个代数方程，解方程比猜通项可靠。

## 图示

```mermaid
flowchart LR
    R[递推关系] --> M[两边乘 z 的 n 次方再求和]
    M --> G[得到 G 的代数方程]
    G --> S[解出 G]
    S --> X[展开成幂级数]
    X --> T[第 n 项系数就是通项]
```

看图的重点是中间那一步：递推为什么会变成方程，因为「n 变成 n−1」在幂级数里就是「乘一个 z」。

## 详解

- 常数数列 1, 1, 1, …：G(z) = 1/(1−z)。
- 自然数列 0, 1, 2, 3, …：G(z) = z/(1−z)²。
- 斐波那契：F(n) = F(n−1) + F(n−2)，可得 G(z) = z/(1 − z − z²)，再分解部分分式就能读出 φ^n 的主项。

**完整实例**：a(n) = a(n−1) + 1，a(0) = 0。
设 G = Σa(n)z^n。对 n ≥ 1 求和：G − a(0) = zG + z/(1−z)。
代入 a(0) = 0：G = zG + z/(1−z)，即 G(1−z) = z/(1−z)，G = z/(1−z)²。
展开得 a(n) = n。代 n = 3 核对：数列 0, 1, 2, 3，一致。

## 常见误解

- 别以为生成函数要求级数收敛才能用——形式幂级数不关心收敛，只关心系数。
- 别把 z 当成一个具体的数——它只是「位置标记」，用来区分第几项。
