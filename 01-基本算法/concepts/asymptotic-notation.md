# 渐近记号与大 O

- **难度**：进阶 | **涉及章节**：第 1 章

## 一句话定义

大 O 记号描述一个函数的增长速度上界：f(n) = O(g(n)) 表示 n 足够大时，f 的增长不会超过 g 的某个常数倍。

## 为什么重要

它是比较算法的通用语言。两个排序算法，一个 O(n²) 一个 O(n log n)，在 n 很大时的高下不用实测就能判断。没有这套记号，算法分析只能停在「跑起来试试」。

## 详解

严格定义：存在正常数 c 与 n₀，使所有 n ≥ n₀ 都有 f(n) ≤ c·g(n)。

**为什么可以只留最高次项**：以 3n² + 5n + 7 为例，取 n₀ = 1，则 5n ≤ 5n²、7 ≤ 7n²，于是整体 ≤ 15n²，c = 15 就满足定义。

**常见阶的关系**：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2^n)。

**实例**：n = 1000 时，log2 n 约 10，n log2 n 约 10000，n² 是 100 万。三者差了五个数量级，这就是为什么 O(n²) 排序在百万级数据上不可用。

## 常见误解

- 别把 O 当成「大约等于」，它是上界，不是等号。
- 别以为 O 越小一定越快，小 n 时常数项可能翻盘。
- 别把 O 和 Θ 混为一谈，Θ 要求上下界同时成立。
