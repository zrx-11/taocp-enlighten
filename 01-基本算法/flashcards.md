# 计算机程序设计艺术 卷1：基本算法 · 抽认卡

## 第 1 章：算法是什么，怎么衡量它

### 卡片：算法的五条准则是什么？
- **背面**：有限性、确定性、输入、输出、可行性。
- **标签**：定义
- **章节**：ch01

### 卡片：证明算法会停，要指出什么？
- **背面**：一个每轮严格减小、又有下界的量，例如欧几里得算法里的余数 r。
- **标签**：终止性
- **章节**：ch01

### 卡片：大 O 的严格定义是什么？
- **背面**：存在正常数 c 与 n₀，使所有 n ≥ n₀ 都有 f(n) ≤ c·g(n)。
- **标签**：复杂度
- **章节**：ch01

### 卡片：3n² + 5n + 7 = O(n²) 的依据是哪两个常数？
- **背面**：取 n₀ = 1、c = 15：5n ≤ 5n²、7 ≤ 7n²，整体不超过 15n²。
- **标签**：复杂度
- **章节**：ch01

## 第 2 章：分析算法要用的数学工具箱

### 卡片：数学归纳法的两步分别叫什么？
- **背面**：奠基（验证起点）与归纳（由 n 成立推出 n+1 成立）。
- **标签**：证明
- **章节**：ch02

### 卡片：等比求和的闭式是什么？
- **背面**：Σ(k=0 到 n) x^k = (1 − x^(n+1))/(1 − x)，x ≠ 1。
- **标签**：求和
- **章节**：ch02

### 卡片：C(n, k) 的帕斯卡递推怎么写？
- **背面**：C(n, k) = C(n−1, k−1) + C(n−1, k)。
- **标签**：组合数
- **章节**：ch02

### 卡片：生成函数把递推变成了什么？
- **背面**：一个关于 z 的代数方程，解出 G(z) 后展开，系数就是通项。
- **标签**：生成函数
- **章节**：ch02

### 卡片：解释程序的三段循环是什么？
- **背面**：取指、译码、执行。

## 第 4 章：线性表

### 卡片：在单链表 P 之后插入 Q 的两步是什么？顺序能反吗？
- **背面**：先 Q.LINK = P.LINK，再 P.LINK = Q；不能反，否则 P 原来的后继地址会被覆盖。
- **标签**：链表
- **章节**：ch04

### 卡片：双链表删除节点 Q 要改哪两条链？
- **背面**：Q.LLINK.RLINK = Q.RLINK；Q.RLINK.LLINK = Q.LLINK。
- **标签**：链表
- **章节**：ch04

### 卡片：队列用普通数组实现会出现什么问题？怎么解决？
- **背面**：假溢出：队首后移留下永久空位。用循环数组，判满条件 (rear+1) mod m = front。
- **标签**：队列
- **章节**：ch04

### 卡片：循环链表用一个指针能访问什么？
- **背面**：从尾指针可以同时到达尾部（它自己）与头部（它的 LINK），插入删除都不必从头遍历。
- **标签**：链表
- **章节**：ch04

## 第 5 章：树、多链结构与动态存储

### 卡片：n 个节点的树有多少条边？为什么？
- **背面**：n − 1 条；除根以外每个节点恰贡献一条连向父节点的边。
- **标签**：树
- **章节**：ch05

### 卡片：三种遍历的差别在哪一点？
- **背面**：访问根的时机：先序最先、中序中间、后序最后。
- **标签**：遍历
- **章节**：ch05

### 卡片：一般树怎么变成二叉树？
- **背面**：用左孩子—右兄弟：LCHILD 指第一个孩子，RSIB 指下一个兄弟。
- **标签**：表示
- **章节**：ch05

### 卡片：扩充二叉树的 E 与 I 有什么关系？
- **背面**：E = I + 2n，n 是内部节点数。
- **标签**：路径长度
- **章节**：ch05

### 卡片：引用计数与标记-清扫各怕什么？
- **背面**：引用计数怕环（互相指向永不归零）；标记-清扫怕暂停（要扫一遍才能回收）。
- **标签**：垃圾回收
- **章节**：ch05

### 卡片：边界标记的作用是什么？
- **背面**：在块头块尾各存大小，使释放时能 O(1) 找到物理相邻的前后块并合并。
- **标签**：存储管理
- **章节**：ch05

### 卡片：伙伴系统怎么找「伙伴」块？
- **背面**：地址与块大小做异或：伙伴地址 = 地址 XOR 长度。只有同尺寸的伙伴才能合并。
- **标签**：存储管理
- **章节**：ch05
