# TAOCP 点化学习系统 · 部署与使用说明

六本 TAOCP 中文版扫描件做成的一套可开学知识库：一个总入口、六个单书伴侣、一套 Markdown 知识库、一份跨书路线。

## 一、最快上手

双击根目录的 `index.html`，就是全部内容。单文件、离线可开，不需要本地服务器。

- 顶部标签切换六本书与「跨书总览」。
- 左侧按「学习路径 / 章节 / 概念 / 测验 / 抽认卡 / 术语 / 模式 / 速查」浏览。
- 搜索框覆盖全部书；进度自动存在浏览器本地，刷新不丢。
- 每本书另有 `学习伴侣.html`，内容同源，可以单独发给别人。

## 三、部署到 GitHub Pages

三步，都在仓库根目录执行：

```bash
# 1. 把本目录的全部文件放进仓库根目录（index.html 必须在根）
git add .
git commit -m "TAOCP 点化学习系统"
git push origin main
```

2. 打开仓库 **Settings → Pages**。
3. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。

等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`。中文目录名与 `_build/` 能正常访问，靠的就是根目录那个 `.nojekyll`——不要删。

**排错**：
- 首页 404：确认 `index.html` 在仓库根，不是在某个子目录里。
- 页面能开但样式全丢：检查是否只上传了部分文件，`index.html` 是自包含的，但伴侣 HTML 与 Markdown 需要同目录文件。
- 中文路径 404：确认 `.nojekyll` 存在且没被 `.gitignore` 忽略。

## 五、已知限制

- **图示渲染**：Mermaid 图依赖 CDN（jsDelivr）。联网时自动渲染成图形；离线时显示为「图示源码」块，内容仍在，格式是文本。这是单文件离线方案的取舍。
- **数学写法**：渲染器不支持 LaTeX，全部公式用纯文本写（`O(n²)`、`x^(n+1)`），保证离线与在线都能读。
- **原文来源**：六本 PDF 是扫描件（合计 3115 页，无文字层），目录与页码经逐页读图核对；正文精讲按主干章节写，不是逐页翻译。
- **范围**：六书全景 + 主干章节精讲。每本书的核心章节有完整点化卡（目标/讲解/图示/实例/误解/自测/锚点），其余章节以结构导航与要点形式覆盖，未逐节展开。

## 六、怎么继续往下学

先读 `00-跨书总览/README.md` 的顺序表，按卷1 → 卷2 → 卷3 → 卷4A → 卷4B 推进，MMIX 可穿插。每章读完做自测，答对再走下一步；每本书读完回到《跨书概念映射表》，看同一概念在别的书里怎么讲。
